# Layth Aziz — Personal Portfolio

A responsive bilingual (Arabic / English) personal portfolio with a dark editorial aesthetic and subtle motion, inspired by the interaction patterns of modern personal portfolios.

## Features
- Arabic RTL and English LTR toggle
- Responsive navigation and layouts for mobile, tablet, and desktop
- Animated hero monogram and orbital rings
- Lightweight canvas particle network
- Scroll reveal transitions and active section navigation
- Animated skill chips and project cards
- Social links: Instagram, TikTok, YouTube, Facebook, and GitHub
- Reduced-motion accessibility support
- No build step required

## Run locally
Open `index.html` in a browser, or run:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000.
